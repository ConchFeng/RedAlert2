# Contributing to VERA20k Conch Edit

Help is welcome. You can write code, refactor the engine, test the game, share ideas, or play
it next to the original and tell us what feels wrong. Open a PR and we'll take it from there.

Contributors can take responsibility for engine areas, with broad freedom to make changes that
move VERA20k Conch Edit forward.

Maintainers will help with review, integration and merging. You'll keep full credit for your
contribution.

Discussion is on [Discord](https://discord.gg/kmjRUn5m5F) and in the QQ group (1097193563).

## Outside contributors and their agents

Follow the scope and done criteria in your issue. Keep each pull request to one
small fix, with one to three focused regression tests that fail without it.
Cite the native function name and address beside gamemd-derived code. Do not
add native-execution corpora. Keep the pull request description to about 15 lines.

The maintainer-agent build runner, retail-data checks, critic reviews, and native
comparison workflow do not apply to outside contributors. The contribution
guidelines and the issue define the contribution's scope.
